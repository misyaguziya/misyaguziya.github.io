# Project artwork

These are the existing project owners' published assets, retrieved on 2026-11-11. The original files are copied unchanged into `public/assets/projects/`, except OSCLogger: its embedded PNG is extracted byte-for-byte from the ICO container for browser compatibility. No pixels are changed. Product covers are framed in CSS to show the existing icon or wordmark without redrawing it. Project names remain available as text to assistive technology.
